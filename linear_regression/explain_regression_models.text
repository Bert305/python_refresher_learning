## 🟩 STEP 1: 📦 Import the tools you'll use

```python
import numpy as np  # helps with numbers and math
import matplotlib.pyplot as plt  # lets us draw charts and graphs
import pandas as pd  # helps us organize and look at data in tables
```

✅ These are Python libraries:

* `numpy` is good for math.
* `matplotlib.pyplot` is for making graphs and charts.
* `pandas` helps organize data like an Excel spreadsheet.

---

## 🟩 STEP 2: 🌐 Load your data from a URL

```python
url = "https://.../FuelConsumptionCo2.csv"
df = pd.read_csv(url)
```

✅ This:

* Downloads a **CSV file** (like an Excel sheet) from the internet.
* Loads it into a **DataFrame** (a table you can work with in Python).
* The variable `df` now holds all the data.

---

## 🟩 STEP 3: 👀 Peek at the data

```python
df.head()        # Shows the first 5 rows
df.sample(5)     # Shows 5 random rows
df.describe()    # Shows stats (like average, min, max) for each column
```

✅ These lines help you **get a feel** for the data:

* What kind of numbers it has
* What the rows look like
* How much each value varies

---

## 🟩 STEP 4: 🧹 Make a smaller version of the table

```python
cdf = df[['ENGINESIZE', 'CYLINDERS', 'FUELCONSUMPTION_COMB', 'CO2EMISSIONS']]
cdf.sample(9)
```

✅ This keeps **only the useful columns**:

* `ENGINESIZE`: how big the engine is
* `CYLINDERS`: how many cylinders in the engine
* `FUELCONSUMPTION_COMB`: average fuel use (combined driving)
* `CO2EMISSIONS`: how much pollution (CO2) the car makes

Now `cdf` is a smaller table (subset) we’ll use for analysis.

---

## 🟩 STEP 5: 📊 Make histograms

```python
viz = cdf[['CYLINDERS','ENGINESIZE','FUELCONSUMPTION_COMB','CO2EMISSIONS']]
viz.hist()
plt.show()
```

✅ This makes **histograms**, which are bar graphs showing how often each value appears. Example:

* How many cars have 4 cylinders?
* How many use 10 L of fuel per 100 km?

`plt.show()` tells Python to **display the graphs**.

---

## 🟩 STEP 6: 🔵 Scatter plots (2-column visual comparisons)

### FUELCONSUMPTION\_COMB vs CO2EMISSIONS

```python
plt.scatter(cdf.FUELCONSUMPTION_COMB, cdf.CO2EMISSIONS, color='blue')
plt.xlabel("FUELCONSUMPTION_COMB")
plt.ylabel("Emission")
plt.show()
```

✅ Each **dot** shows one car.

* X-axis = how much fuel the car uses.
* Y-axis = how much CO2 it emits.

This graph helps answer:

> "Does more fuel = more pollution?"

---

### ENGINESIZE vs CO2EMISSIONS

plt.scatter(cdf.ENGINESIZE, cdf.CO2EMISSIONS, color='blue')

✅ This shows:
